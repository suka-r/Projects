# Phone Book

**High School Computing Science** · Python · Sep 2022 – Jan 2023

A console contact lookup for a small company directory.

## Features
- Greets the user by name, then lists the available contacts
- Choose a contact by letter, then choose which details to show: phone number, address, email, or all information
- Contact data is kept in a separate module (`database.py`), apart from the program logic (`Phone_book.py`)

## Run it
Requires Python 3 (standard library only). Run it from inside this folder:
```
python Phone_book.py
```
