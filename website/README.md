# Casa Decor – E-commerce Website

**High School Computing Science (CS 20)** · HTML · CSS · JavaScript · Sep 2022 – Jan 2023

A front-end storefront for a fictional furniture shop, Casa Decor.

## Features
- **Dynamic product grid:** product cards (image, name, price, description) are generated with JavaScript from a data array in `js/products.js`, three per row
- **Product detail overlay:** clicking a product card or a sidebar link opens a modal that shows the product's image, model number, price, and full description
- **Layout:** header with logo and breadcrumb-style menu, sidebar product links, and a Flexbox product layout

## Run it
No setup needed. Open `index.html` in any web browser.

## Files
```
website/
├── index.html          # page layout and rendering/overlay script
├── css/stylesheet.css  # styling
├── js/products.js      # product data
└── img/                # logos and product images
```
