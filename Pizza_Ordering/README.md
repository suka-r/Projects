# Pizza Ordering System

**High School Computing Science** · Python · Sep 2021 – Jan 2022

A console ordering app for a pretend in-school pizza delivery service, "Eastglen Pizza Classroom Delivery".

## Features
- Collects the student's name, student ID, and classroom
- Size selection: Small ($10), Medium ($12), Large ($15)
- Topping selection from 7 options at $3.00 each; type `done` to finish
- Estimates delivery time as the current time plus 15 minutes, using Python's `datetime` module
- Prints a formatted receipt with the order details and total

## Run it
Requires Python 3 (standard library only).
```
python pizza.py
```
